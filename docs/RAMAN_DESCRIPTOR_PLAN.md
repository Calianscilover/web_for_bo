# 拉曼溶剂化描述符规划

## 1. 目标

把每个电解液样品的拉曼光谱，用固定脚本转换为一组低维、物理可解释的
溶剂化描述符向量，作为贝叶斯主动学习中代理模型的物理增强输入，使溶剂化
信息从"后验机理分析"前置到"采集决策"。

约束：

- 不使用需要训练的光谱模型；只用积分、分位数和固定组分线性分解。
- 描述符定义一经冻结，在整个主动学习过程中不变，保证各轮数据语义一致。
- 每个描述符必须对候选池中所有配方都有定义（定长、无缺失）。

## 2. 配方空间与对描述符的含义

配方空间来自 `pool/config_snapshot.json`，候选池 `pool/pool.csv` 共 9,656 个配方。


| 组分     | 角色         | 范围                         | 在候选池中出现比例 | 拉曼处理           |
| ------ | ---------- | -------------------------- | --------- | -------------- |
| LiDFOB | 主盐         | 1.0–2.5 mol/L              | 100%      | 阴离子侧描述符的来源     |
| NDFA   | 配位溶剂（平衡溶剂） | NDFA:LiDFOB = 1–5（摩尔比）     | 100%      | 溶剂侧描述符：自由/配位分数 |
| TTE    | 稀释剂        | 溶剂池 0–50 wt%               | 53%       | 不建描述符；作为谱带位移质控 |
| FEC    | 共溶剂        | 溶剂池 0–35 wt%（FEC:Li ≤ 4.2） | 51%       | 溶剂侧描述符：配位量     |
| LiNO3  | 锂盐添加剂      | 0–2 wt%（NO3⁻:DFOB⁻ ≤ 0.41） | 49%       | 可选描述符          |
| VC     | 功能添加剂      | 0–5 wt%                    | 50%       | 含量低，不建描述符      |
| TMSP   | 功能添加剂      | 0–5 wt%                    | 50%       | 含量低，不建描述符      |


空间特征决定了描述符设计的重点：

1. **单盐**：阴离子谱带窗口和参考位置全程固定，不需要跨盐归一化。
2. **NDFA:Li 只有 1–5**：处于高浓 / 局部高浓区间，DFOB⁻ 以接触离子对（CIP）
  和聚集体（AGG）为主，溶剂分离离子对（SSIP）占比可能很小。描述符的动态范围
   主要在 CIP↔AGG 之间，以及"自由 NDFA 是否残留"。
3. **TTE 是稀释剂**：本身基本不进入 Li⁺ 第一溶剂化壳，它的影响应通过阴离子聚集
  程度体现，而不是通过 TTE 自身的谱带。
4. **组分存在与否是离散的**：FEC、LiNO3 约一半配方不含，溶剂侧描述符必须定义为
  "每个 Li⁺ 的配位量"，组分不存在时自然取 0，而不是写成缺失值。



## 3. 描述符定义



### 3.1 核心描述符（必选）


| 编号  | 名称          | 定义                                                                             | 物理含义                  |
| --- | ----------- | ------------------------------------------------------------------------------ | --------------------- |
| A1  | DFOB⁻ 谱带重心  | \mu=\int \nu I(\nu)d\nu / \int I(\nu)d\nu，在固定阴离子窗口内                            | 阴离子平均配位环境             |
| A2  | DFOB⁻ 峰位    | 平滑后峰顶 ±3 点抛物线拟合的亚像素极大值位置                                                       | 主导环境的位置               |
| A3  | DFOB⁻ 分位数宽度 | (\nu_{84}-\nu_{16})/2，\nu_p 为窗口内累积面积 p% 分位点                                    | 阴离子环境的异质性             |
| A4  | DFOB⁻ 聚集分数  | 固定分割点 \nu_\text{split} 以上面积占窗口总面积比例                                            | AGG（相对 CIP/SSIP）占比    |
| S1  | 自由 NDFA 量   | n_\text{NDFA,free}=(1-f_\text{coord,NDFA})\cdot n_\text{NDFA}/n_\text{Li}      | 每个 Li⁺ 对应的未配位 NDFA 数  |
| S2  | 配位 FEC 量    | n_\text{FEC,coord}=f_\text{coord,FEC}\cdot n_\text{FEC}/n_\text{Li}；无 FEC 时为 0 | 每个 Li⁺ 第一溶剂化壳中的 FEC 数 |


说明：

- n_\text{Li} 只计 LiDFOB 的 Li⁺；含 LiNO3 时其 Li⁺ 另行记录，不并入分母，
以保持 S1/S2 与配方摩尔比的直接对应。
- f_\text{coord} 由该溶剂"自由 / 配位"谱带对的面积分数得到；
拉曼散射截面差异不做校正，只要求与真实配位比例单调一致。
- 由于 n_\text{NDFA}/n_\text{Li} 已由配方决定，配位 NDFA 量与 S1 之和等于已知
组分比，两者只取 S1，避免与组分输入完全共线。



### 3.2 A1 与 A2 的冗余处理

高浓区单峰为主时，A1 与 A2 可能高度相关（|r| > 0.95）。冻结前在参考谱和预实验
数据上计算二者相关系数：

- |r| ≤ 0.95：A1、A2 均保留。
- |r| > 0.95：A2 替换为不对称度 \nu_\text{peak}-\mu，与 A1 近似正交，
并能指示第二环境的出现。



### 3.3 A4 的升级选项

`若参考谱能确认 DFOB⁻ 各环境的子峰位置与峰宽，A4 升级为固定组分非负最小二乘 分解（NNLS）：`

1. 用参考谱全局拟合确定各子峰（CIP、AGG，必要时 SSIP）的中心与宽度，
  线型取 pseudo-Voigt，参数冻结。
2. 每条新谱只拟合非负振幅，中心允许 ±0.5–1 cm⁻¹ 微调。
3. 输出 f_\text{AGG}（及 f_\text{CIP}）；进入模型前做 log-ratio 变换，
  如 \log(f_\text{AGG}/f_\text{CIP})。

固定分割点版本与 NNLS 版本只保留一个。

### 3.4 可选描述符


| 编号  | 名称        | 定义                                                            | 启用条件                   |
| --- | --------- | ------------------------------------------------------------- | ---------------------- |
| O1  | NO3⁻ 配位程度 | NO3⁻ 对称伸缩谱带（约 1040 cm⁻¹ 附近，以参考谱为准）的重心相对其自由态位置的位移；无 LiNO3 时取 0 | 2 wt% 时信噪比满足第 6 节重复性关卡 |
| O2  | 溶剂化壳总配位数  | n_\text{NDFA,coord}+n_\text{FEC,coord}                        | 需要压缩维度或用于机理解释时         |




### 3.5 质控量（不进入模型）


| 编号  | 名称         | 用途                       |
| --- | ---------- | ------------------------ |
| Q1  | TTE 特征谱带位移 | 应接近 0；偏离说明校准漂移或 TTE 参与配位 |
| Q2  | 溶剂扣除残差     | 阴离子窗口内扣除后残差的相对能量，超阈值标记样品 |
| Q3  | 参考样漂移      | 每批测量的固定参考样 A1 与历史均值之差    |




### 3.6 最终输入向量

```text
核心版（6 维）：[A1, A2 或 ν_peak-μ, A3, A4, S1, S2]
最小版（4 维）：[A1, A3, A4, S1]   # 用于小样本阶段或关卡未全部通过时
```

进入代理模型前统一做 z-score 标准化，标准化参数在冻结时确定，后续轮次不重算。

## 4. 光谱处理流程

```text
原始光谱
  |
  +--> 1. 波数校准（Si 520.7 cm⁻¹ 或氖灯），每批一次
  +--> 2. 去宇宙射线
  +--> 3. 基线扣除（arPLS，锚点区间固定）
  +--> 4. 溶剂背景扣除（阴离子窗口内）
  +--> 5. 固定窗口积分 -> A1-A4
  +--> 6. 溶剂谱带对分解 -> f_coord,NDFA, f_coord,FEC -> S1, S2
  +--> 7. 质控量 Q1-Q3 与标记
  |
  +--> raman_descriptors.csv
```



### 4.1 阴离子窗口选择原则

DFOB⁻ 的分析谱带由参考谱确定，选择时依次满足：

1. 在 LiDFOB/NDFA 浓度系列中可见明确的随浓度位移或形变。
2. 与 NDFA、TTE、FEC、VC、TMSP 纯组分谱带重叠最少。
  需特别检查 C=O 伸缩区：DFOB⁻ 草酸根 C=O 与 FEC、VC 的 C=O 谱带位置接近，
   若选用该区，FEC 存在时必须执行 4.2 的扣除。
3. 窗口两侧有可用的基线锚点。

窗口确定后记录为 [\nu_\text{lo}, \nu_\text{hi}]、\nu_\text{split}、基线锚点，
写入处理配置并冻结。

### 4.2 溶剂背景扣除

溶剂比例在配方间连续变化，落入阴离子窗口的溶剂信号随之变化；不扣除时，
A1–A4 会混入组分信息。步骤：

1. 背景模型 B(\nu)=\sum_i s_iS_i(\nu)，S_i 为纯组分参考谱。
2. 缩放系数 s_i 由各组分在窗口外、不与阴离子重叠的特征谱带拟合得到。
3. 从光谱中减去 B(\nu) 后计算 A1–A4。
  1. 若配位态溶剂谱带本身移入窗口、纯溶剂谱扣不干净，改为在窗口内对
    "DFOB⁻ 各环境 + 重叠溶剂自由 / 配位态"做联合固定组分分解。



### 4.3 溶剂侧谱带对


| 组分   | 需要确定的谱带对                                | 确定方式                 |
| ---- | --------------------------------------- | -------------------- |
| NDFA | 自由态 / Li⁺ 配位态（候选：酰胺 C=O、C–N 或 CF3 相关模式） | LiDFOB/NDFA 浓度系列     |
| FEC  | 自由态 / Li⁺ 配位态（候选：环呼吸或 C=O 模式）           | 固定 NDFA:Li 下的 FEC 系列 |
| TTE  | 单一特征谱带（不应位移）                            | TTE 稀释系列，用作 Q1       |


谱带位置全部以本平台参考谱为准，不直接套用文献值。

## 5. 参考谱库（主动学习启动前一次性完成）


| 编号  | 样品组              | 内容                                       | 用途                                                  |
| --- | ---------------- | ---------------------------------------- | --------------------------------------------------- |
| R0  | 纯组分              | NDFA、TTE、FEC、VC、TMSP；LiDFOB、LiNO3 固体     | 窗口选择、背景扣除                                           |
| R1  | 无盐溶剂混合物          | NDFA+TTE、NDFA+FEC、NDFA+TTE+FEC，各 2–3 个比例 | 验证扣除流程；溶剂间相互作用基线                                    |
| R2  | LiDFOB/NDFA 浓度系列 | NDFA:Li = 20、10、5、4、3、2、1                | 定 SSIP/CIP/AGG 参考位置、NDFA 谱带对；NDFA:Li > 5 的点用于锚定低聚集端 |
| R3  | TTE 稀释系列         | NDFA:Li = 2 和 4，TTE 0–50 wt%             | 稀释剂对聚集的影响；Q1                                        |
| R4  | FEC 系列           | NDFA:Li = 2 和 4，FEC 0–35 wt%             | FEC 谱带对；FEC 与阴离子窗口重叠评估                              |
| R5  | LiNO3 系列         | 固定基础配方，LiNO3 0、1、2 wt%                   | O1 是否可用                                             |
| R6  | 重复性组             | 10–15 个覆盖空间的配方，各测 3–5 次，含重新配制            | 第 6 节关卡 1                                           |


测量条件固定并记录：激光波长与功率、积分时间与累加次数、25 °C 控温、
密封比色皿或毛细管。LiDFOB 与 TMSP 对水分敏感，样品须在惰性气氛中封装，
避免水解产物谱带干扰。

## 6. 冻结前的验证关卡

逐关通过后描述符定义才冻结，未通过的描述符从向量中移除。


| 关卡        | 检验                           | 通过标准                                              |
| --------- | ---------------------------- | ------------------------------------------------- |
| 1. 重复性    | R6 组内与组间方差                   | 组内相关系数 ICC ≥ 0.8                                  |
| 2. 预处理敏感性 | 窗口边界 ±2–5 cm⁻¹、基线参数、扣除缩放系数扰动 | 描述符变化 < 样品间标准差的 20%                               |
| 3. 扣除有效性  | R1 无盐混合物走完整流程                | 阴离子窗口残差接近噪声水平                                     |
| 4. 物理一致性  | R2、R3 系列                     | A1/A4 随 NDFA:Li 降低单调上升；S1 随 NDFA:Li 降低趋近 0；Q1 ≈ 0 |
| 5. 动态范围   | 覆盖空间的预实验样品                   | 描述符跨样品范围 ≥ 5 倍重复测量标准差                             |
| 6. 冗余     | 描述符间相关矩阵                     | 任意两维                                              |


关卡 1–5 只需要光谱，不需要电化学数据，可在提案阶段作为预实验完成。

## 7. 与主动学习流程的衔接

候选池 9,656 个配方无法全部测拉曼，因此候选打分时需要处理"候选尚无光谱"。
按阶段推进：

### 7.1 阶段一：组成 → 描述符映射

1. 在候选池中按空间填充选取约 100–200 个配方测拉曼，加上每轮被选中做电化学
  的样品。
2. 用摩尔比特征训练"组成 → 描述符"的多输出 GP，预测全池描述符及不确定度。
3. 判据：留一交叉验证 R² ≥ 0.9 视为映射可靠。



### 7.2 阶段二：性能代理模型接入

按阶段一判据选择：


| 情况       | 方案                                                        |
| -------- | --------------------------------------------------------- |
| 映射可靠     | 级联：性能模型输入为 [组成, 描述符]；Thompson 采样时先从描述符后验抽样，再从性能后验抽样       |
| 映射不可靠    | 两阶段筛选：组成模型从全池初选约 48 个候选，实测拉曼得到描述符，再用含描述符的模型重新打分，选出每轮 16 个 |
| 采用 DKL 时 | 描述符作为隐空间的辅助预测目标：损失为性能负对数边际似然加 λ 倍描述符负对数边际似然，候选打分不需要光谱     |




### 7.3 增益评估

与仅用组成的基线在相同数据下比较：

- 负对数似然、2σ 区间实际覆盖率；
- Spearman 秩相关；
- 前 k 名配方命中率；
- 回溯模拟：按实验轮次时间切分，用前几轮训练、预测下一轮。

拉曼描述符在本空间中是组成的确定性函数，评估关注的是"更好的坐标"带来的
预测与校准提升，以及可解释性（各描述符的长度尺度或重要性），而非新增变量。

## 8. 输出文件



### 8.1 `raman_descriptors.csv`

以 `sample_id` 与 `pool/converted/pool_catalog.csv` 对应，一行一次测量：

```text
sample_id
measurement_id
batch_id
A1_centroid_cm1
A2_peak_cm1            # 或 A2_asym_cm1，取决于 3.2
A3_qwidth_cm1
A4_agg_fraction
S1_ndfa_free_per_li
S2_fec_coord_per_li
O1_no3_shift_cm1       # 可选
Q1_tte_shift_cm1
Q2_subtraction_residual
Q3_reference_drift_cm1
qc_flag
```

同一 `sample_id` 多次测量时，模型使用均值，组内标准差作为观测噪声估计。

### 8.2 `raman_manifest.json`

记录并冻结处理配置：

- 阴离子窗口 [\nu_\text{lo}, \nu_\text{hi}]、\nu_\text{split}、基线锚点；
- 各溶剂谱带对位置与积分区间；
- 参考谱文件及其 SHA-256；
- NNLS 子峰参数（若启用）；
- 标准化均值与标准差；
- 脚本版本与生成时间。

处理配置任何改动都生成新版本号，旧数据须用新配置重新处理后才能混用。
